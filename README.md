# Batman Keychain - 3D CAD Design

## 📌 Project Overview
This repository contains a 3D-printable model of a Batman keychain, designed using Onshape. The project demonstrates fundamental CAD skills, including importing 2D vector graphics, applying accurate dimensions, and using 3D extrusion features to create a functional physical object.

---

## ⚙️ Design Specifications & Requirements

* Base Profile: The iconic Batman logo, imported as a high-precision DXF vector file to avoid manual tracing errors.
* Overall Size: Scaled to a practical width of 60 mm, which is the ideal standard size for a pocket keychain.
* Thickness (Extrusion): The 2D sketch was extruded to a solid depth of 2 mm.
* Mounting Hole: A 4 mm diameter center-point circle was strategically placed at the top center of the design to serve as the keyring hole, ensuring structural integrity around the edges.
